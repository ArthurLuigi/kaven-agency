# Política de Segurança

## Versões suportadas

A versão publicada a partir da branch `main` recebe correções de segurança.

## Reportar uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades ou dados sensíveis.

Envie o relato para [contato.kavenagency@gmail.com](mailto:contato.kavenagency@gmail.com) com:

- descrição do problema;
- passos mínimos para reprodução;
- impacto observado ou potencial;
- arquivos ou rotas afetadas;
- sugestão de correção, quando disponível.

Evite incluir credenciais reais, dados de clientes ou informações pessoais. O recebimento será confirmado e a correção será priorizada conforme impacto e explorabilidade.

## Boas práticas para contribuições

- Não versione arquivos `.env.local`, tokens ou chaves privadas.
- Atualize dependências somente com testes e build aprovados.
- Trate conteúdo de formulários como entrada não confiável.
- Prefira pull requests pequenos, revisáveis e acompanhados de validação.
